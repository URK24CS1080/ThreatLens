College Viva MongoDB Setup Instructions:

If running local MongoDB on Windows, open PowerShell as Administrator and run: net start MongoDB (or run mongod). Alternatively, use a free cloud cluster from MongoDB Atlas and set your connection string in .env: 

MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/threatlens

You can also run python database/mongo_cli.py --inspect in your terminal to view collections and take your viva screenshot.
